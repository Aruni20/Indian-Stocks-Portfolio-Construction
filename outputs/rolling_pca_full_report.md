# One-year rolling PCA portfolio report

Each calendar year uses the preceding one-year return history to estimate PCA weights. The portfolio is rebalanced monthly, quarterly, half-yearly, or yearly. Results cover 2017 through the latest available 2026 observations.

At each rebalance, returns are standardized, PCA is computed by SVD, and the best-Sharpe portfolio among the first five principal components is selected. Component loadings are converted to long-only normalized weights.

## Interpretation

Returns are compounded daily portfolio returns within each calendar year. 2026 is partial and should not be compared directly with full years. These are PCA-only results; equal-weight, minimum-risk, and maximum-Sharpe benchmark portfolios are not included in this report.
